# Photo Mapping: Moonlit Stone

A synthetic facade demonstrates moving grazing light, relative depth and masked openings. The photo, depth and mask fields are analytic demo data; this example does not estimate depth or demonstrate model accuracy.

Set `switch_calibration` to 1 for the regular alignment chart, or 0 for the effect. Both paths pass through the same surface mask, Grid Warp and Corner Pin before Window Out. The Output viewer shows the reference preview; Window Out carries the calibrated projection.

Adjust the effect's speed, depth strength and depth range. Use Grid Warp and Corner Pin to align the projector. For a real photo and reusable EXR maps, use File → Map from photo.
