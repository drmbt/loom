# Photo Mapping: Liquid Strata

Luminous ribbons follow the relative depth of a synthetic facade. Photo detail, depth relief and mask coverage have separate roles. All demo fields are analytic; no model or download is required.

Set `switch_calibration` to 1 to inspect the regular alignment chart through the same mask, Grid Warp, Corner Pin and Window Out path. Return to 0 for the ribbons. Change the effect's speed, bands, glow and depth range to explore the surface.

The Output viewer previews the reference photograph and light together. Window Out carries the projection. File → Map from photo creates the equivalent editable setup with your photo and float32 EXR maps.
